## 1. 面接官の名前を面接結果に自動で記載

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 面接官 - ユーザー型 - フィールド名 q_interviewer
- 面接結果 - 文字型 - フィールド名 q_interview_result

面接官の名前を面接結果に自動で記載したいです。
```

### 回答

```
- EL式：#{#q_interviewer?.getName()}
- #q_interviewer（ユーザー型）
- 設定対象のデータ項目: q_interview_result（文字型）
```
