# ユーザー型データに関する文法知識

業務プロセスで「ユーザー型」データを扱う場合、  ユーザーの情報を取得するために専用メソッドを使用します。  
以下では、ユーザー型の基本概念と利用可能なメソッドを整理します。


## 1. ユーザー型の基本概念

- ユーザー型は、ワークフローに登録された **ユーザーを選択するデータ型**です。
- 保存される情報は主に次の通りです。
  - ユーザーID
  - ユーザー名
  - メールアドレス
- **単一選択のデータ型**です。
- タスク担当者の設定やメール送信先などで利用されます。


## 2. SpELの注意

- ユーザー型の変数は `#q_user` のように記述します。
- 直接参照した場合、**ユーザー名とメールアドレスを含む文字列**が返ります。

例：

`#q_user`

出力例：

田中 徹 &lt;tanaka@questetra.com&gt;


## 3. ユーザー型のメソッド

### getId()

- **説明**：ユーザーIDを取得します。
- **入力**：ユーザー型
- **返り値の型**：Long
- **例**

`#q_user?.getId()`


### getName()

- **説明**：ユーザー名を取得します。
- **入力**：ユーザー型
- **返り値の型**：文字型
- **例**

`#q_user?.getName()`


### getEmail()

- **説明**：ユーザーのメールアドレスを取得します。
- **入力**：ユーザー型
- **返り値の型**：文字型
- **例**

`#q_user?.getEmail()`


### isDeleted()

- **説明**：ユーザーが削除済みかどうかを判定します。
- **入力**：ユーザー型
- **返り値の型**：Boolean
- **例**

`#q_user?.isDeleted()`


### isDeletedInFuture()

- **説明**：ユーザーが将来削除予定かどうかを判定します。
- **入力**：ユーザー型
- **返り値の型**：Boolean
- **例**

`#q_user?.isDeletedInFuture()`
