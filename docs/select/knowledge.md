# 選択型データに関する文法知識

業務プロセスで「選択型」データを扱う場合、 選択型の情報を取得するために専用メソッドを使用します。  
以下では選択型の基本概念と利用可能なメソッドを整理します。


## 1. 選択型の基本概念

### IDとLabelの関係

選択型データ項目では、**ID（選択肢ID）**と**Label（表示ラベル）**の2つの要素が重要です：

- **ID（選択肢ID）**：データベースに保存される実際の値（例：`ja`, `br`）
- **Label（表示ラベル）**：ユーザーに表示される人間が読みやすい文字列（例：`Japan`, `Brazil`）

**重要なポイント：**

- データ更新時は**ID**を使用して選択肢を指定します
- ユーザーが画面で見るのは**Label**ですが、システム内部では**ID**で処理されます
- EL式で選択型を操作する際は、常に**ID**を基準に考えてください


## 2. 選択型データの種類と特徴


選択型データには以下の4つのタイプがあり、それぞれ異なる特性と用途を持ちます：

### 1. ラジオボタン

- **特徴**：候補を一覧表示し、その中から一つを選択
- **選択数**：単一選択のみ
- **用途**：必須項目で、複数候補から一つを選ぶ場合
- **例**：承認ステータス（承認済み/保留中/却下）

### 2. チェックボックス

- **特徴**：複数の候補から複数選択可能
- **選択数**：複数選択可能（0個〜最大設定数まで）
- **用途**：任意項目で、複数の選択肢を同時に選ぶ場合
- **例**：機能選択（機能A/機能B/機能C）

### 3. セレクトボックス

- **特徴**：プルダウンメニューから一つを選択
- **選択数**：単一選択のみ
- **用途**：候補数が多い場合のコンパクトな表示
- **例**：部門選択（営業部/開発部/総務部...）

### 4. 検索セレクトボックス

- **特徴**：検索入力により大量の候補から一つを選択
- **選択数**：単一選択のみ
- **用途**：候補数が非常に多い場合（数百〜数千件）
- **例**：ユーザー選択、商品選択


## 3. 選択型のメソッド

### 直接参照

- **説明**：選択肢の ID を直接指定して選択する、または文字型データに入力されたIDから選択します。
※複数IDはカンマ区切りまたは改行区切りで記述できます。
- **入力**：選択型
- **返り値の型**：選択型
- **引数**：
    - 直接指定：`{'ja', 'br'}`
    - 文字型参照：`#q_string`
- **例**：

```
// 直接指定
{'ja', 'br'} // ID ja と br を選択、データ更新の欄にそのまま代入する
// 出力 : Japan, Brazil

// 文字型参照
#q_string = "ja,br"
データ更新に入力する式 : #q_string
// 出力 : Japan, Brazil
```

### get(int)

- **説明**：チェックボックスで選択された要素をインデックス指定で取得します。
- **入力**：選択型
- **返り値の型**：単一型
- **引数**：int  (インデックス番号、0から開始)
- **例**：

```
#q_check?.get(0)?.getDisplay()
#q_check?.get(1)?.getDisplay()
// 出力： Japan Brazil
```

### split('\n')

- **説明**：文字型データを分割して配列化します。Questetra は配列を自動的にリストと解釈します。
- **入力**：文字型
- **返り値の型**：文字型の配列型
- **引数**：文字型

splitメソッドの文字列の長さを返したい場合はlengthメソッドを使います。例を参照、 ( )は不要


- **例**：

```
#q_string_multi = "1\n2\n3"
#q_string_multi?.split("\n")?.length
//出力： 3
```

### split(':')

- **説明**：文字型データを分割して配列化します。Questetra は配列を自動的にリストと解釈します。
- **入力**：文字型
- **返り値の型**：文字型の配列型
- **引数**：文字型（区切り文字 ":"）

splitメソッドの文字列の長さを返したい場合はlengthメソッドを使います。例を参照、 ( )は不要

- **例**：

```
#q_string_single = "1:2:3"
#q_string_single?.split(":")?.length
//出力： 3
```

### isEmpty()

- **説明**：リストが空かどうかを判定し、Boolean（true/false）を返します。
- **入力**：選択型
- **返り値の型**：Boolean
- **引数**：なし
- **例**：

```
#q_check?.?[value == '3']?.isEmpty() // true または false
```

### size()

- **説明**：リストの要素数を取得します。
- **入力**：選択型
- **返り値の型**：整数型
- **引数**：なし
- **例**：

```
#q_check?.size() // 選択された要素の数を返す
```
