### 1. 顧客メッセージに応じた対応状況の自動更新

#### 質問
```
ワークフローアプリには、以下のデータ項目があります。
- 顧客メッセージ　- 文字型（複数行）　- フィールド名 q_customer_message
- 対応状況　- 文字型　- フィールド名 q_support_status

顧客メッセージの内容に応じて、対応状況を自動更新したいです。
```

#### 回答

```
提案1：
- EL式：£{#q_customer_message?.contains('緊急') ? '高優先' : '通常'}
- #q_customer_message（文字型（複数行））
- 設定対象のデータ項目: q_support_status（文字型）

提案2：
- EL式：£{#q_customer_message?.contains('クレーム') ? '要対応' : '対応済'}
- #q_customer_message（文字型（複数行））
- 設定対象のデータ項目: q_support_status（文字型）
```

### 5. エラーログの最初の行をエラー概要に設定

#### 質問

```

ワークフローアプリには、以下のデータ項目があります。
- エラーログ　- 文字型（複数行）　- フィールド名 q_error_log
- エラー概要　- 文字型　- フィールド名 q_error_summary

エラーログの最初の行をエラー概要に設定したいです。
```

#### 回答

```
提案1：
- EL式：£{#q_error_log?.split('\n')?.length > 0 ? #q_error_log?.split('\n')[0] : ''}
- #q_error_log（文字型（複数行））
- 設定対象のデータ項目: q_error_summary（文字型）
```
