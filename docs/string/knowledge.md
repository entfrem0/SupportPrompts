# 文字型データに関する文法知識

業務プロセスで「文字型」データを扱う場合、 文字の情報を取得するために専用メソッドを使用します。  
以下では、文字型の基本概念と利用可能なメソッドを整理します。


## 1. 文字型の基本概念

- 組織型は、ワークフローに登録された **文字を扱うデータ型**です。文字型には3種類あります。

### 1. 文字型 (単一行)

1行のみの文字しか入力できず、改行(\n)ができません。

### 2. 文字型 (複数行)

複数行文字を入力できます。

### 3. 文字型 (Markdown)

Markdown形式で文字を入力できます。クエステトラ上ではユーザーはMarkdownの出力結果を見ることができます。


## 2. SpELの注意

- 文字型の変数は `#q_string` のように記述します。
- 直接参照した場合、文字列が返ります。

例：

`#q_string`

出力例：

Customer Service


## 3. 文字型のメソッド

### equals(str)

- **説明**：文字列が等しいか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** : 
  - str : 比較対象の文字型
- **例**
```
#q_string?.equals(#q_char)
#q_stirng?.equals('ja')
```

### length()

- **説明**：文字列の長さを返します。
- **入力**：文字型
- **返り値の型**：int
- **引数** : なし
- **例**
`#q_string?.length()`

### contains(str)

- **説明**：指定文字列を含むか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.contains('ja')`

### startsWith()

- **説明**：指定文字列で始まるか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.startsWith('ja')`

### endsWith()

- **説明**：指定文字列で終わるか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.endsWith('br')`

### split(str)

- **説明**：文字列を区切り文字で分割し、リスト化します。
- **入力**：文字型
- **返り値の型**：文字型の配列
- **引数** :
  - str : 区切り文字 (文字型)

仕様上splitメソッドは改行\nを置換対象の文字列にしたり置換後の文字列にすることができません。
splitメソッドの文字列の長さを返したい場合はlengthメソッドを使います。例を参照、 ( )は不要

- **例**
```
#q_string?.split(',')?.length

#q_string?.split('\n')?.length
→\nが含まれると正常に動作しない。
```

### replace(str1,str2)

- **説明**：文字列を置換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** :
  - str1 : 置換対象文字列
  - str2 : 置換後文字列
仕様上replaceメソッドは改行\nを置換対象の文字列にしたり置換後の文字列にすることはできません。

- **例**
```
#q_string?.replace(',', ':')

#q_string?.replace(',', '\n')
→\nが含まれると正常に動作しない。
```

### toUpperCase()

- **説明**：大文字に変換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.toUpperCase()`

### toLowerCase()

- **説明**：小文字に変換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.toLowerCase()`

### trim()

- **説明**：前後の空白を削除します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.trim()`
