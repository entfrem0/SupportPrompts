## データ更新工程の概要

「データ更新」とは、業務データを指定の値または式の評価結果によって自動的に更新する工程です。

### 仕様および注意点
- ひとつの工程で複数のデータ項目を同時に更新できます  
- 更新値は固定値でもよく、EL式（SpEL）による動的な評価結果を使うこともできます  
- 工程の設定では、対象データの選択、値または式の編集、参照の挿入（プロセス開始日時やユーザ名など）が可能です。ただしデータ型によっては値のクリアのみが可能です  
- [データ更新]工程において、書式を何も設定しない場合は空値（`null`）が設定され、元のデータは消去されます  
- 複数の項目に値を設定する場合、それらは同時に評価され、順序は保証されません  

次に、「データ更新」に使える文字型の設定書式と変換操作の方法について説明します。

## 文字型データに関する文法知識


業務プロセスで文字型データを操作する際には、それぞれの特性と目的に応じて適切なメソッドを使い分ける必要があります。以下では、すべてのメソッドとその機能を分類して紹介します。


### 1. 文字型の特性

- 組織型は、ワークフローに登録された **文字を扱うデータ型**です。文字型には3種類あります。

#### 1. 文字型 (単一行)

1行のみの文字しか入力できず、改行(\n)ができません。

#### 2. 文字型 (複数行)

複数行文字を入力できます。

#### 3. 文字型 (Markdown)

Markdown形式で文字を入力できます。クエステトラ上ではユーザーはMarkdownの出力結果を見ることができます。


### 2. SpELの注意

- 文字型の変数は `#q_string` のように記述します。
- 直接参照した場合、文字列が返ります。

例：

`#q_string`

出力例：

Customer Service


### 3. 文字型のメソッド

対象オブジェクトのデータ型を文字型に分けて、よく使われるメソッドを整理します。

#### equals(str)

- **説明**：文字列が等しいか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** : 
  - str : 比較対象の文字型
- **例**
```
#q_string?.equals(#q_char)
#q_stirng?.equals('ja')
```

#### length()

- **説明**：文字列の長さを返します。
- **入力**：文字型
- **返り値の型**：int
- **引数** : なし
- **例**
`#q_string?.length()`

#### contains(str)

- **説明**：指定文字列を含むか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.contains('ja')`

#### startsWith()

- **説明**：指定文字列で始まるか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.startsWith('ja')`

#### endsWith()

- **説明**：指定文字列で終わるか判定します。
- **入力**：文字型
- **返り値の型**：Boolean
- **引数** :
  - str : 文字型
- **例**
`#q_string?.endsWith('br')`

#### split(str)

- **説明**：文字列を区切り文字で分割し、リスト化します。
- **入力**：文字型
- **返り値の型**：文字型の配列
- **引数** :
  - str : 区切り文字 (文字型)

仕様上splitメソッドは改行\nを置換対象の文字列にしたり置換後の文字列にすることができません。
splitメソッドの文字列の長さを返したい場合はlengthメソッドを使います。例を参照、 ( )は不要

- **例**
```
#q_string?.split(',')?.length

#q_string?.split('\n')?.length
→\nが含まれると正常に動作しない。
```

#### replace(str1,str2)

- **説明**：文字列を置換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** :
  - str1 : 置換対象文字列
  - str2 : 置換後文字列
仕様上replaceメソッドは改行\nを置換対象の文字列にしたり置換後の文字列にすることはできません。

- **例**
```
#q_string?.replace(',', ':')

#q_string?.replace(',', '\n')
→\nが含まれると正常に動作しない。
```

#### toUpperCase()

- **説明**：大文字に変換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.toUpperCase()`

#### toLowerCase()

- **説明**：小文字に変換します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.toLowerCase()`

#### trim()

- **説明**：前後の空白を削除します。
- **入力**：文字型
- **返り値の型**：文字型
- **引数** : なし
- **例**
`#q_string?.trim()`
