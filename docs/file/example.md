## 1. 見積書のファイルサイズチェック

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 見積書 - ファイル型 - フィールド名 q_estimate_file
- 見積書ステータス - 選択型 - フィールド名 q_estimate_status

見積書のファイルサイズが1MB以上の場合、見積書ステータスを「要確認」に更新したいです。
```

### 回答

```
提案1：
- EL式：#{#q_estimate_file != null && #q_estimate_file[0] != null && #q_estimate_file[0]?.getLength() >= 1048576 ? {'review'} : ''} 
- #q_estimate_file（ファイル型）
- 設定対象のデータ項目: q_estimate_status（選択型）

理由：
- ファイルサイズが1MB（1,048,576バイト）以上の場合、見積書ステータスを「要確認」に設定
- null安全性を確保するためのチェックを含む
- 選択型の場合は選択肢IDを使用（'review'は「要確認」の選択肢ID）
```


## 2. マルウェアスキャンステータスチェック

### 質問

```
ワークフローアプリには、以下のデータ項目があります。

- 添付書類 - ファイル型 - フィールド名 q_attached_document
- マルウェアチェック結果 - 文字型 - フィールド名 q_malware_check_result

添付書類のマルウェアスキャンステータスが「THREATS_FOUND」の場合、マルウェアチェック結果に「危険なファイルが検出されました」と自動設定したいです。
```

### 回答

```
提案1：
- EL式：#{#q_attached_document != null && #q_attached_document[0] != null && #q_attached_document[0]?.getMalwareScanStatus() == 'THREATS_FOUND' ? '危険なファイルが検出されました' : ''}
- #q_attached_document（ファイル型）
- 設定対象のデータ項目: q_malware_check_result（文字型）

理由：
- マルウェアスキャンステータスが「THREATS_FOUND」の場合、警告メッセージを設定
- null安全性を確保するためのチェックを含む
```

## 3. 契約書ファイル名の自動設定

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 契約書 - ファイル型 - フィールド名 q_contract_file
- 契約書名 - 文字型 - フィールド名 q_contract_name

契約書のファイル名を契約書名として自動設定したいです。
```

### 回答

```
提案1：
- EL式：#{#q_contract_file != null && #q_contract_file[0] != null ? #q_contract_file[0]?.getName() : ''}
- #q_contract_file（ファイル型）
- 設定対象のデータ項目: q_contract_name（文字型）

理由：
- ファイルが存在する場合、そのファイル名を契約書名として設定
- null安全性を確保するためのチェックを含む
```


## 4. 画像ファイルの種別判定

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 画像ファイル - ファイル型 - フィールド名 q_image_file
- 画像種別 - 選択型 - フィールド名 q_image_type

アップロードされた画像ファイルが画像形式の場合、画像種別を「画像」に設定したいです。
```

### 回答

```
提案1：
- EL式：#{#q_image_file != null && #q_image_file[0] != null && #q_image_file[0]?.isImage() == true ? {'image'} : ''}
- #q_image_file（ファイル型）
- 設定対象のデータ項目: q_image_type（選択型）

理由：
- ファイルが画像形式の場合、画像種別を「画像」に設定
- null安全性を確保するためのチェックを含む
- 選択型の場合は選択肢IDを使用（'image'は「画像」の選択肢ID）
```


## 5. ファイルサイズ警告

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 報告書 - ファイル型 - フィールド名 q_report_file
- ファイルサイズ警告 - 文字型 - フィールド名 q_file_size_warning

報告書のファイルサイズが10MBを超える場合、ファイルサイズ警告に「ファイルサイズが大きすぎます」と設定したいです。
```

### 回答

```
提案1：
- EL式：#{#q_report_file != null && #q_report_file[0] != null && #q_report_file[0]?.getLength() > 10485760 ? 'ファイルサイズが大きすぎます' : ''}
- #q_report_file（ファイル型）
- 設定対象のデータ項目: q_file_size_warning（文字型）

理由：
- ファイルサイズが10MB（10,485,760バイト）を超える場合、警告メッセージを設定
- null安全性を確保するためのチェックを含む

```
