ここでは前提と実現したい処理内容とEL式の記述例を掲載します。

## 1. 承認状況の更新

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 担当部署 - 組織型 - フィールド名 q_department
- 承認状況 - 文字型 - フィールド名 q_approval_status

承認状況を「承認済み」に更新したいです。
```

### 回答

```
提案1：
- EL式：'承認済み'
- #q_department（組織型）
- 設定対象のデータ項目: q_approval_status（文字型）
```

## 4. 発注書メモへの部署名挿入

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 発注部署 - 組織型 - フィールド名 q_purchasing_department
- 発注書メモ - 文字型 - フィールド名 q_purchase_memo

発注書メモに担当部署名を自動挿入したいです。
```

### 回答

```
提案1：
- EL式：#{#q_purchasing_department?.getName()}
- #q_purchasing_department（組織型）
- 設定対象のデータ項目: q_purchase_memo（文字型）
```

## 5. トレーニングログへの組織名追記

### 質問

```
ワークフローアプリには、以下のデータ項目があります。
- 研修担当組織 - 組織型 - フィールド名 q_training_group
- トレーニングログ - 文字型 - フィールド名 q_training_log

トレーニングログに研修担当組織の名前を追記したいです。
```

### 回答

```
提案1：
- EL式：#{#q_training_log + ' ' + #q_training_group?.getName()}
- #q_training_group（組織型）
- 設定対象のデータ項目: q_training_log（文字型）
```
